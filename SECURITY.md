# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | :white_check_mark: |
| 1.x     | :x:                |

## Reporting a Vulnerability

Laravel AI Guard is a security package, so vulnerability reports are taken seriously and handled with priority.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, report them privately via one of these channels:

- **GitHub Security Advisories** (preferred): [Report a vulnerability](https://github.com/jay123anta/laravel-ai-guard/security/advisories/new)
- **Email**: [jay123anta@gmail.com](mailto:jay123anta@gmail.com) with the subject line `[SECURITY] laravel-ai-guard`

### What to include

- A description of the vulnerability and its impact
- Steps to reproduce (a failing test case or proof-of-concept is ideal)
- Affected version(s)
- Any suggested fix, if you have one

### What to expect

- **Acknowledgement** within 72 hours
- **Assessment and fix timeline** communicated within 7 days
- **Credit** in the release notes and CHANGELOG once the fix ships (unless you prefer to remain anonymous)

### Scope notes

Reports about detection **bypasses** (a bot or injection payload that evades the signatures) are welcome, but please file them as regular GitHub issues unless the bypass itself exposes user data or breaks the host application — signature gaps are expected and iterated on publicly.
